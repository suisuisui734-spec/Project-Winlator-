# Project Winlator — Brand/UI refresh

## Visual direction
- Product identity: **PROJECT WINLATOR**
- Palette: deep navy surfaces, electric cyan primary accent, warm amber secondary accent.
- Logo: angular W mark split cyan/amber; no Winlator Mali legacy logo reuse.
- Launcher background: dark geometric/ring motif.
- Drawer cover: custom vector skyline and cyan/amber W accents.
- Drawer sections: GAME LIBRARY, TOOLS & RUNTIME, SYSTEM.
- Toolbar: dark navy 56dp brand surface.

## Scope of this pass
This is an additive visual identity refresh for the launcher icon, drawer cover/header, navigation category labels, and shared theme colors. Existing navigation destinations and graphics-driver selections are unchanged.

## Next UI pass
- Home dashboard with quick-launch/continue card and recent shortcuts.
- Library grid/list toggle with search and sort.
- Container cards with clearer status and actions.
- Settings grouped into searchable sections.
- UI mockup is concept reference only; metrics shown in concept art are not implemented telemetry and must not be represented as live data.

## Validation
Run Android CI, compile resource XML, assemble APK, and lint. Test light/dark modes, launcher icon variants, drawer layout, and navigation. No GPU/FPS performance changes are part of this UI PR.
